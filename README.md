# Django Expense Tracker

A full-stack Expense Tracker web application built using Django, SQLite, HTML/CSS, and Matplotlib.

---

## Features

- Add Expenses
- Edit Expenses
- Expense Table
- Category-wise Pie Chart
- Dynamic Total Calculation
- Browser Favicon
- Clean UI

---

## Technologies Used

- Python
- Django
- SQLite
- HTML
- CSS
- Matplotlib

---

## Project Structure

```bash
expense_tracker/
│
├── expense_tracker/
├── expenses/
├── static/

├── db.sqlite3
```

---

## How to Run

### Clone Repository

```bash
git clone https://github.com/mdjaheerashraf/python-expense-tracker-django.git
```

### Install Requirements

```bash
pip install django
pip install matplotlib
```

### Run Server

```bash
python manage.py runserver
```
